Задание:

Создайте экран с карточкой профиля:

- сверху круглый аватар с инициалами `Т`;
- рядом имя: `Тилек Абдрахманов`;
- ниже профессия: `Android-разработчик`;
- затем строка со статистикой:
    - `12` — проектов;
    - `48` — задач;
    - `5` — лет опыта;
- внизу две кнопки: `Написать` и `Подписаться`.

Требования к Compose:

```text
Column
 └─ Box с фоном
     ├─ Row: аватар + имя и профессия
     ├─ Row: три блока статистики
     └─ Row: две кнопки
```

Для практики используйте:

- `Column` и `Row`;
- `weight(1f)` — чтобы три блока статистики были одинаковой ширины;
- `horizontalAlignment` и `verticalAlignment`;
- `padding`, `background`, `clip`;
- `Arrangement.spacedBy`;
- `Text` с разными `fontSize`, `fontWeight` и цветами.

Дополнительное задание: сделайте список из трёх таких карточек, используя `users.forEach { user -> ... }`.
