# Расчёт балла за модуль

Каждый модуль оценивается максимум в **30 баллов**:

- лабораторные работы — до **20 баллов**;
- тест — до **10 баллов**;
- дополнительные достижения и активность — до **8 бонусных баллов**;
- пропуски и опоздания снижают итоговый результат.

## Формула

$$
\text{Балл за модуль} =
\min\left(30,\;
\max\left(0,\; L + T - 1.5P - 0.5O + B\right)\right)
$$

где:

| Обозначение | Значение | Ограничение |
|---|---|---:|
| `L` | Баллы за 4 лабораторные работы | `0 ≤ L ≤ 20` |
| `T` | Баллы за тест | `0 ≤ T ≤ 10` |
| `P` | Количество пропусков без уважительной причины | `P ≥ 0` |
| `O` | Количество опозданий | `O ≥ 0` |
| `B` | Дополнительные баллы | `0 ≤ B ≤ 8` |

## Штрафы за посещаемость

- Один пропуск без уважительной причины: **−1.5 балла**.
- Одно опоздание: **−0.5 балла**.
- Подтверждённые пропуски по уважительной причине не учитываются в `P`.

## Бонусные баллы

Дополнительные баллы начисляются за активность, которая помогает освоению дисциплины:

- участие или призовое место в олимпиаде / конкурсе по теме курса;
- качественный доклад или презентация;
- содержательная активность на занятиях;
- выполнение дополнительного практического задания;
- помощь в подготовке учебных материалов.

Суммарно за модуль:

$$
0 \leq B \leq 8
$$

## Пример расчёта

Студент получил:

- `L = 18` баллов за лабораторные;
- `T = 8` баллов за тест;
- `P = 2` пропуска;
- `O = 3` опоздания;
- `B = 4` бонусных балла.

$$
18 + 8 - 1.5 \cdot 2 - 0.5 \cdot 3 + 4 = 25.5
$$

Итоговый балл за модуль: **25.5 из 30**.

## Итоговая оценка за дисциплину

$$
\text{Итог} = M_1 + M_2 + E
$$

где:

- `M₁` — первый модуль, максимум 30 баллов;
- `M₂` — второй модуль, максимум 30 баллов;
- `E` — экзамен, максимум 40 баллов.

Максимальный итоговый результат по дисциплине — **100 баллов**.
