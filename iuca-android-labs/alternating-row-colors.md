# Alternating Row Colors in Jetpack Compose

Based on the provided classwork, modify the `Greeting` composable.

## Requirements

1. Make all odd rows use the standard primary color.
2. Make every even row use a grey background color.
3. In each even row, randomly select several letter boxes and change their background to yellow.

## Expected Result

Words are shown as rows of letter boxes. Every second row is grey, with some randomly highlighted yellow letter boxes.
